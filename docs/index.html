Noah_Demo

An Android application built for CPEN 321 (Software Engineering) at the University of British Columbia.

What it does

Noah_Demo is a coursework project with three independent features:

  • Login and server information: signs in with Google, then displays the server's and client's IP addresses and local times, retrieved over HTTPS from its own back-end.
  • Live updates: renders a 16×16 pixel image as it is painted one cell at a time, relayed through the back-end over a websocket.
  • Timer: a countdown that, when it reaches zero, starts a memory game played with original 8-bit style sprites.

Google Sign-In

The app uses Google Sign-In only to display the signed-in user's first and last name on screen. It requests basic profile scopes and nothing else.
